Core Features (Unchanged)
---------------------------
Bans & Unbans:
   /eb ban <player> [reason]         - Permanent ban
   /eb tban <player> <time> [reason] - Temporary ban
   /eb unban <player>                - Remove ban

Freeze:
   /eb freeze <player> [time] [reason] - Freeze player
   /eb unfreeze <player>               - Unfreeze player

Warnings:
   /eb warn <player> [reason]  - Warn player
   /eb unwarn <player>         - Remove warning

Management:
   /eb reload   - Reload configuration
   /eb update   - Check for updates
   /eb banlist  - View ban list
   /eb help     - Show help
   /eb version  - Show version

Usage Steps
-----------
1. Build:
   mvn clean package

2. Install:
   - Copy ExtraBan-2.1.0.jar to plugins/
   - Restart the server

3. Configure:
   - Edit config.yml in plugins/ExtraBan/
   - Assign permissions

4. Use:
   - Use available commands
   - Check messages and notifications
